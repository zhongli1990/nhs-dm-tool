# Release Notes v0.2.6

Date: 2026-06-01

## Summary

v0.2.6 is a credential-hygiene release, part of a portfolio-wide IP-protection / password-rotation pass. No functional or schema changes.

## Key updates

1. Default bootstrap admin password rotated
- The default value of `DMM_BOOTSTRAP_ADMIN_PASSWORD` was changed from `ChangeMeNow!123` to `Windsor_789+` in the backend bootstrap (`services/backend/app/saas_store.py`) and in the `docker-compose.yml` default.
- The "using default value" production warning now triggers on the new default, preserving the "set a strong secret for production" guidance.
- `.env` / `.env.example` continue to use placeholders and are unaffected.

## Not in this release (tracked follow-up)

- The default seeded organisation/admin still references **QVH** (`qvh_admin`, `qvh.nhs.uk`). De-identifying seed/demo data to remove the specific NHS Trust reference is tracked as a separate, verified change so it can be confirmed not to break seed lookups.
